Cómo restaurar

  1. Entra al servidor por SSH.
  2. Copia y pega el comando del respaldo elegido (arriba). Para un .zip descargado, súbelo al servidor y usa su ruta: bash scripts/respaldos/restaurar.sh ~/archivo.zip.
  3. El script verifica el respaldo y te muestra qué contiene. Si todo está bien, te pide escribir el dominio de este servidor para confirmar.
  4. Antes de reemplazar nada guarda una copia de lo actual («Antes de restaurar»), detiene la app y el importador, restaura, los vuelve a encender y comprueba que el sistema responda.

Se niega si el respaldo está dañado, si es de otro dominio (salvo que agregues --otro-destino, para un servidor nuevo) o si es de una versión más nueva que el código instalado. En un servidor nuevo, pon primero el .env (usa env.plantilla del respaldo como guía).
