Tablas de datos — Scroll horizontal en móvil

Componente cerrado. Tabla real, sin transformar, envuelta en overflow-x-auto con ancho mínimo — en pantallas angostas se desliza en vez de romper el layout. Las acciones CRUD (Editar / Resetear / Activar / Desactivar) son íconos accesibles coloreados por rol semántico — mismo lenguaje de color que Botones y Badges (Editar/Ver = primary, Resetear = warning, Activar = success, Desactivar/Eliminar = danger), no un gris neutro. Código fuente: src/app/web/templates/components/_tablas.html (macro accion_icono(...)). Tokens documentados en docs/design-system/tokens.md.
