Tarjeta de /mis-paquetes — 3 alternativas

Mismo dato base que hoy (nombre, estado, ubicación, fecha) con 4 paquetes de ejemplo (uno por estado) para comparar cómo se ve cada alternativa en los 4 casos reales. La estructura general de la vista (pestañas, detalle expandible) no cambia — solo el contenido de la tarjeta colapsada.

Alternativa A

Ícono de estado

Un ícono circular a la izquierda identifica el estado de un vistazo (antes de leer el badge de texto) — la forma del ícono ayuda a alguien que hojea rápido la lista, no solo el color.

Dato destacado a la derecha

Alternativa C

Mini progreso de ciclo de vida

Una barra de 3 segmentos (Anunciado → Recibido → Entregado) arriba de cada tarjeta muestra en qué parte del camino va el paquete sin tener que leer el badge. Cancelado rompe el patrón a propósito (barra roja completa) para que se note distinto al resto, no como "un paso más".
