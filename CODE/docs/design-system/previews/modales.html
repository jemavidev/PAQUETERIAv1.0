Modales / confirmación — Centrado + chips de pocas opciones

Componente cerrado. Código fuente: src/app/web/templates/components/_modales.html (macros modal(...), modal_confirmacion(...), grupo_chips(...)). Tokens documentados en docs/design-system/tokens.md. Cuando un <select> dentro de un modal tiene menos de 5 opciones, no va como lista desplegable — las opciones se muestran directo en pantalla como chips clickeables (un solo tap, sin abrir/cerrar nada). Con 5 o más, sigue siendo un <select> normal (evita que la tarjeta crezca sin límite). Implementación sin JS: son <input type="radio"> reales ocultos (sr-only) con su <label> estilizado vía peer-checked — accesibles y navegables por teclado igual que un select nativo, cero JavaScript.
