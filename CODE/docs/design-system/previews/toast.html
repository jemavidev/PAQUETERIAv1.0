Alertas / notificaciones — Toast flotante con auto-dismiss

Componente cerrado. Reemplaza el <div class="error">/<div class="ok"> repetido a mano en ~10 plantillas. Código fuente: src/app/web/templates/components/_toast.html (macro toast(...)). Tokens documentados en docs/design-system/tokens.md. El caso real de PaqueteX: base.html tiene una barra de navegación inferior fija (.site-footer-mobile, position:fixed; bottom:0) visible en todos los anchos de pantalla, no solo móvil — el body le reserva padding-bottom:80px (56px de nav con íconos + 24px de línea de crédito "Desarrollado por JEMAVI", agregada para igualar el footer real de producción). Si el toast se ancla a bottom-4, queda literalmente encima de esos botones de navegación. El mockup de abajo simula esa barra real (con su línea de crédito) para mostrar la corrección: el toast se ancla con el mismo margen que ya reserva el body (80px) más un respiro, nunca menos.
