====================================================
COMANDOS PARA EJECUTAR EN STAGING (uno por uno)
====================================================

Conecta a tu servidor staging por SSH y ejecuta estos comandos:

1️⃣ Ir al directorio del proyecto:
----------------------------------------------------
cd /ruta/al/proyecto
# (donde está el docker-compose.yml)


2️⃣ Verificar configuración de rutas:
----------------------------------------------------
docker-compose exec web python debug_routes.py


3️⃣ Reiniciar el servidor:
----------------------------------------------------
docker-compose restart web


4️⃣ Verificar que esté corriendo:
----------------------------------------------------
docker-compose ps


5️⃣ Ver logs recientes:
----------------------------------------------------
docker-compose logs --tail=30 web


6️⃣ Probar el portal con curl:
----------------------------------------------------
curl -I https://staging.jemavi.co/customer-portal


7️⃣ Probar API de OTP:
----------------------------------------------------
curl -X POST https://staging.jemavi.co/api/customer-portal/request-otp \
  -H "Content-Type: application/json" \
  -d '{"phone": "+573334004007"}'


====================================================
ALTERNATIVA: Ejecutar todo de una vez
====================================================

Copia y pega este bloque completo:

bash EJECUTAR_EN_STAGING.sh


====================================================
SI AÚN HAY PROBLEMAS
====================================================

Rebuild completo:
----------------------------------------------------
docker-compose down
docker-compose up -d --build
docker-compose exec web alembic upgrade head


Ver logs en tiempo real:
----------------------------------------------------
docker-compose logs -f web | grep -i "customer-portal\|auth"


Verificar archivo de configuración:
----------------------------------------------------
docker-compose exec web cat src/app/config_routes.py | grep -A 3 "customer-portal"


====================================================
PRUEBA FINAL EN NAVEGADOR
====================================================

Abre en ventana privada/incógnito:
https://staging.jemavi.co/customer-portal

Debería mostrar el formulario del portal, NO redirigir a login.
