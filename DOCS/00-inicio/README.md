# 🚀 Inicio Rápido

## Documentos en esta carpeta

- **EMPEZAR_AQUI.txt** - Punto de inicio para nuevos desarrolladores
- **LEEME_PRIMERO.txt** - Información esencial antes de empezar
- **QUICK_START_STAGING.md** - Guía rápida para staging
- **CUFE_QUICK_START.md** - Inicio rápido para funcionalidad CUFE

## Orden Recomendado

1. Lee `EMPEZAR_AQUI.txt` o `LEEME_PRIMERO.txt`
2. Configura tu entorno según `QUICK_START_STAGING.md`
3. Si trabajas con facturas, revisa `CUFE_QUICK_START.md`
