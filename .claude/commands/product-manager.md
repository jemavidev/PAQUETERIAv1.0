# Product Manager Agent Command

This command invokes the **Product Manager** specialist agent from the BetterAgents ecosystem.

## Capabilities
- Product strategy and vision definition
- User story writing with acceptance criteria
- Feature prioritization (RICE, MoSCoW)
- Product roadmap creation
- KPI and metrics definition
- User research analysis
- Competitive analysis
- Go-to-market strategy
- Product Requirements Documents (PRD)

## Usage
Describe your product challenge. The PM will:
- Define clear user stories with acceptance criteria
- Prioritize features objectively with scoring
- Create structured roadmaps
- Define measurable success metrics
- Identify scope and constraints

## Example Prompts
- "Write user stories for our checkout flow"
- "Prioritize these 5 features using RICE"
- "Create a Q1 product roadmap for our MVP"
- "Define KPIs for our new onboarding feature"
- "Write a PRD for the user authentication system"

Route this request to the product-manager agent with the user's full context.
