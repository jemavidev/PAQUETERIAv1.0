# Data Scientist Agent Command

This command invokes the **Data Scientist** specialist agent from the BetterAgents ecosystem.

## Capabilities
- Exploratory data analysis (EDA)
- Machine learning model design and evaluation
- Statistical analysis and hypothesis testing
- A/B test design and analysis
- Feature engineering
- Time series analysis
- Natural language processing
- Data visualization recommendations

## Usage
Share your data challenge or dataset description. The Data Scientist will:
- Design the analysis approach
- Write Python code using pandas, scikit-learn, scipy
- Select appropriate algorithms with reasoning
- Interpret results and provide actionable insights
- Identify caveats and limitations

## Example Prompts
- "Analyze this user churn dataset for insights"
- "Build a classification model to predict customer behavior"
- "Design an A/B test for our new onboarding flow"
- "Find patterns in this sales data"
- "Which ML algorithm should I use for this problem?"

Route this request to the data-scientist agent with the user's full context.
