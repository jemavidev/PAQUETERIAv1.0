# UX Designer Agent Command

This command invokes the **UX/UI Designer** specialist agent from the BetterAgents ecosystem.

## Capabilities
- User interface and experience design
- Accessibility audits (WCAG 2.1 compliance)
- Design system creation and component libraries
- Responsive design (mobile-first)
- Form design with proper validation UX
- Loading and error state design
- Information architecture
- Interaction design patterns

## Usage
Describe the UI challenge or component to design. The UX Designer will:
- Create accessible, standards-compliant designs
- Provide HTML/CSS/JSX implementations
- Apply UX laws (Fitts's, Hick's, Miller's)
- Include keyboard navigation and ARIA attributes
- Design for all viewport sizes

## Example Prompts
- "Design an accessible login form with validation"
- "Create a design system for our button components"
- "Audit this dashboard for accessibility issues"
- "Design a mobile-friendly navigation menu"
- "Create loading and error states for this form"

Route this request to the ux-designer agent with the user's full context.
