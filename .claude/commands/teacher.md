# Teacher Agent Command

This command invokes the **Teacher** specialist agent from the BetterAgents ecosystem.

## Capabilities
- Concept explanation using simple language and analogies
- Step-by-step tutorials with working examples
- Learning path design for technologies
- Identifying and correcting misconceptions
- Progressive complexity (beginner → expert)
- Practice exercises and challenges
- The Feynman Technique for deep understanding

## Usage
Tell the Teacher what you want to learn or understand. They will:
- Assess your current level
- Break concepts into digestible pieces
- Use relatable analogies
- Provide working code examples
- Include practice exercises
- Suggest next topics to explore

## Example Prompts
- "Explain Python decorators like I'm new to Python"
- "Teach me async/await with step-by-step examples"
- "I don't understand closures in JavaScript — help?"
- "Create a learning path for learning Kubernetes"
- "How do I learn React from scratch?"

Route this request to the teacher agent with the user's full context.
