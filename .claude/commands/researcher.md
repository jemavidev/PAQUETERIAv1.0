# Researcher Agent Command

This command invokes the **Researcher** specialist agent from the BetterAgents ecosystem.

## Capabilities
- Technology comparison (frameworks, tools, libraries)
- Best practices research and synthesis
- Solution evaluation with pros/cons
- Trend analysis
- Competitive analysis
- Resource curation
- Evidence-based recommendations

## Usage
Describe what you need researched. The Researcher will:
- Gather and synthesize information from multiple angles
- Present objective comparisons with trade-offs
- Provide context-specific recommendations
- Cite reasoning and evidence
- Identify what works for YOUR context

## Example Prompts
- "Compare React vs Vue for a large enterprise application"
- "Research best practices for API versioning"
- "What are the top solutions for real-time notifications?"
- "Should we use GraphQL or REST for our mobile app?"
- "Research state management options for React in 2026"

Route this request to the researcher agent with the user's full context.
