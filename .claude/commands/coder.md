# Coder Agent Command

This command invokes the **Software Coder** specialist agent from the BetterAgents ecosystem.

## Capabilities
- Feature implementation following clean code principles
- Code review and quality assessment
- Refactoring and optimization
- Debugging and root cause analysis
- Language-specific best practices (Python, TypeScript, Go, and more)
- Design pattern implementation
- Error handling and edge case management

## Usage
Provide your implementation request or code to review. The Coder will:
- Write clean, well-documented code
- Identify and fix issues with explanations
- Suggest improvements with reasoning
- Follow SOLID principles and avoid code smells

## Example Prompts
- "Implement JWT authentication in Python"
- "Review this code for issues and improvements"
- "Debug this error: [paste error message and code]"
- "Refactor this function to be more readable"
- "Implement a rate limiter in TypeScript"

Route this request to the coder agent with the user's full context.
