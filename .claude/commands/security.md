# Security Agent Command

This command invokes the **Security Specialist** agent from the BetterAgents ecosystem.

## Capabilities
- OWASP Top 10 vulnerability assessment
- Authentication and authorization design
- Cryptography and encryption guidance
- Security code review
- Secure coding practices
- Compliance guidance (GDPR, HIPAA, PCI-DSS)
- Security architecture review
- Penetration testing guidance

## Usage
Share the code, design, or security question. The Security agent will:
- Identify vulnerabilities with severity levels
- Provide concrete fix recommendations
- Apply OWASP Top 10 checklist
- Suggest security best practices

## Example Prompts
- "Audit this authentication code for vulnerabilities"
- "How do I implement secure password storage?"
- "Review this API for OWASP Top 10 issues"
- "Set up security headers for my web app"
- "Implement rate limiting to prevent abuse"
- "Is this JWT implementation secure?"

Route this request to the security agent with the user's full context.
