# Architect Agent Command

This command invokes the **Software Architect** specialist agent from the BetterAgents ecosystem.

## Capabilities
- System architecture design and review
- SOLID principles and design patterns
- Microservices vs Monolith decisions
- API design (REST, GraphQL, gRPC)
- Database schema design and optimization
- Scalability and performance planning
- Technology stack evaluation
- Cloud architecture (AWS, GCP, Azure)
- Domain-Driven Design, CQRS, Event Sourcing

## Usage
Describe your architecture challenge and the Architect will provide:
- Structured architecture proposals with trade-offs
- Component diagrams and data flows
- Technology recommendations with alternatives
- Scalability and security considerations

## Example Prompts
- "Design an authentication system for 100k users"
- "Should I use microservices or a monolith for this project?"
- "Review this database schema for a multi-tenant SaaS"
- "Design a caching strategy for this high-traffic API"
- "Evaluate GraphQL vs REST for our mobile app"

Route this request to the architect agent with the user's full context.
