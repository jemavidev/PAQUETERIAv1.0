# Tester Agent Command

This command invokes the **Software Tester** specialist agent from the BetterAgents ecosystem.

## Capabilities
- Test strategy design (unit, integration, E2E)
- TDD (Test-Driven Development) guidance
- Test case identification including edge cases
- Testing framework recommendations
- Test coverage analysis
- Bug reproduction and reporting
- Performance testing guidance
- QA process design

## Usage
Describe the feature or code you need tested. The Tester will:
- Design a comprehensive test strategy
- Write test cases using the AAA pattern
- Identify edge cases and error scenarios
- Recommend appropriate testing frameworks
- Define coverage goals

## Example Prompts
- "What tests should I write for this authentication module?"
- "Write unit tests for this payment processing function"
- "Identify edge cases for this data validation logic"
- "Help me set up TDD for this new feature"
- "Review my test coverage for this service"

Route this request to the tester agent with the user's full context.
