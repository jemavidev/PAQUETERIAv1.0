# Writer Agent Command

This command invokes the **Technical Writer** specialist agent from the BetterAgents ecosystem.

## Capabilities
- README files and project documentation
- API documentation (OpenAPI/Swagger)
- Technical tutorials and step-by-step guides
- Code comments and docstrings
- User manuals and onboarding guides
- Release notes and changelogs
- Architecture documentation
- Developer guides

## Usage
Describe the documentation you need. The Writer will:
- Create clear, concise technical documentation
- Follow the "What → Why → How" hierarchy
- Include working code examples
- Use active voice and direct language
- Structure for your target audience

## Example Prompts
- "Write API documentation for this REST endpoint"
- "Create a README for this open-source project"
- "Write a beginner tutorial for setting up this service"
- "Document this function with proper docstrings"
- "Create a changelog entry for v2.0 release"

Route this request to the writer agent with the user's full context.
