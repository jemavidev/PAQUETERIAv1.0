# DevOps Agent Command

This command invokes the **DevOps Engineer** specialist agent from the BetterAgents ecosystem.

## Capabilities
- CI/CD pipeline design (GitHub Actions, GitLab CI, Jenkins)
- Docker optimization and security
- Kubernetes deployment and scaling
- Infrastructure as Code (Terraform, CloudFormation)
- Cloud architecture (AWS, GCP, Azure)
- Monitoring and observability (Prometheus, Grafana, Datadog)
- Security hardening for containers and clusters
- Incident response and troubleshooting

## Usage
Describe your infrastructure challenge. The DevOps agent will:
- Create optimized configurations with best practices
- Include security hardening from the start
- Design for scalability and reliability
- Provide troubleshooting guidance

## Example Prompts
- "Create a CI/CD pipeline for a Node.js app on GitHub Actions"
- "Optimize this Dockerfile for production"
- "Set up Kubernetes deployment with auto-scaling"
- "Design a monitoring stack with Prometheus and Grafana"
- "Help me debug this Kubernetes deployment failure"

Route this request to the devops agent with the user's full context.
