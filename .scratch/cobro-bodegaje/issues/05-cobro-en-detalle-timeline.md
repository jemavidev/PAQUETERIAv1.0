# 05 — Cobro visible en el detalle/timeline del paquete

**What to build:** cualquier miembro del staff puede ver, en el detalle/timeline de un paquete ya
`Entregado`, el monto cobrado (o "$0" + motivo) — sin ser admin.

**Blocked by:** 02 — Entrega atómica con cobro.

**Status:** ready-for-agent

- [ ] El detalle de un paquete `Entregado` muestra el monto cobrado, o "$0" + el motivo elegido
- [ ] Un paquete `Anunciado`/`Recibido`/`Cancelado` no muestra ninguna mención de cobro (no tiene
      `Cobro` asociado)
- [ ] Visible para cualquier rol de staff, no exclusivo de admin
