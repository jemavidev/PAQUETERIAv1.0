📋 Leyenda de Botones

Copiar CUFE

Copia el código CUFE completo al portapapeles. Aparece en la columna CUFE.

Descargar PDF

Descarga el archivo PDF original desde AWS S3. Solo aparece si existe el archivo.

Editar

Abre el modal para editar los datos de la factura.

Eliminar

Elimina la factura y todos sus productos asociados.

⚠️ Si no ves estos botones en tu aplicación

  1. Reinicia el servidor FastAPI
  2. Limpia la caché del navegador (Ctrl + Shift + R)
  3. Recarga la página /invoices
